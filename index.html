Guía rápida de uso

  1. Seleccione los puntajes de R1 a R5 según sus datos de campo y laboratorio.
  2. El sistema suma R1 + R2 + R3 + R4 + R5 para obtener el RMR básico.
  3. Seleccione el tipo de estructura y la orientación para obtener F₀.
  4. Se calcula el RMR final y se muestra la clase obtenida.
  5. El GIF cambia automáticamente según la clase RMR y muestra el sostenimiento típico.

Guía de fórmulas y asignación de puntajes

1) Fórmulas generales

RMRb = R1 + R2 + R3 + R4 + R5

RMR final = RMRb + F₀

2) Significado de cada parámetro

  • R1: resistencia de la roca intacta.
  • R2: RQD del macizo.
  • R3: espaciamiento de discontinuidades.
  • R4: condición de las discontinuidades.
  • R5: condición de agua subterránea.
